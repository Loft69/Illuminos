# Illuminos — онлайн-кинотеатр

Учебный проект по учебной практике ПМ.01 (специальность 09.02.07).
Стек: PHP (PDO) + MySQL + Bootstrap 5 + JavaScript.

## Что нового (обновление дизайна и функций)
Прежние возможности сохранены, схема БД не менялась.
- Герой-карусель новинок (автосмена, пауза, миниатюры, свайп, клавиши ← →).
- Ленты карточек со стрелками; генерируемые постеры; единые компоненты `src/components/helpers.php`.
- Подсказки при вводе в поиск (`/index.php?action=suggest`), клавиша `/` для быстрого поиска.
- Каталог: фильтры по жанру + типу + сортировка (параметры сохраняются), сброс фильтров.
- Избранное: синхронизация кнопок на странице, уведомления с «Вернуть», кнопка для гостей (предложит войти);
  на страницах фильма/сериала добавлены «В избранное», «Трейлер», «Поделиться».
- Сериал: сезоны сворачиваются, видны число эпизодов и длительность.
- Кабинет: аватар, счётчики, прогресс подписки, история платежей, очистка истории (`cabinet.php?action=clear_history`).
- Оплата: подтверждение покупки, отметка «Ваш тариф», защита от повторной оплаты при обновлении страницы.
- Формы: проверка полей на лету, показать пароль, надёжность пароля, проверка занятости логина
  (`auth.php?action=check_login`), состояния загрузки.
- Исправлено: кнопка избранного позиционировалась относительно страницы, а не карточки;
  повторные открытия страницы не плодят записи истории (интервал 10 минут).

## Установка
1. Создайте БД: импортируйте `database/illuminos.sql` в PhpMyAdmin.
2. Укажите доступы к БД в `backend/config.php`.
3. Откройте сайт через локальный сервер (Apache/Nginx + PHP 8).

## Структура
```
Illuminos/
├── index.php            # главная: новинки, популярное, категории, поиск, рекомендации
├── movie.php            # страница фильма (описание, актёры, трейлер, похожие)
├── serial.php           # страница сериала (+ сезоны и эпизоды)
├── cabinet.php          # личный кабинет (история, подписка, избранное)
├── payment.php          # страница оплаты тарифов
├── register.php/login.php # формы регистрации и авторизации
├── backend/             # config.php (БД), auth.php (сессии, роли)
├── src/components/      # header.php, footer.php, head-assets.php, helpers.php
├── public/css/          # style.css (палитра, адаптив)
├── public/js/           # main.js (валидация без перезагрузки, избранное)
├── docs/                # palette.md, prototype.md, mockup.md
└── database/illuminos.sql
```
