# Дизайн-макеты (Mockup) Illuminos

Реализованы в `public/css/style.css` на Bootstrap 5 (сетка) + CSS-переменные палитры в стиле **Кинопоиск**.

## Требования графического дизайна
- Цветовая гамма: графитовая тёмная тема (фон `#1D1D1D`, карточки `#272727`), фирменный оранжевый акцент `#FF6C00`,
  зелёный бейдж рейтинга `#3BB33B` — контраст WCAG AA.
- Сетка: Bootstrap (container → row → col), карточки контента
  с постерами 2:3, скругление 8 px, лёгкое увеличение (scale 1.03) при наведении.
- Свободное пространство: аккуратные отступы между секциями,
  внутри карточек — 12 px.
- Типографика: шрифт Inter (Google Fonts), заголовки 700.

## Адаптивные макеты (мобильные / планшетные устройства)
| Устройство        | Брейкпоинт | Сетка карточек          |
|-------------------|------------|-------------------------|
| Смартфон          | < 576 px   | 2 карточки в ряду       |
| Планшет (портрет) | 576–991 px | 3–4 карточки в ряду     |
| Планшет/ноутбук   | 992–1199 px| 4 карточки в ряду       |
| Десктоп           | ≥ 1200 px  | 6 карточек в ряду       |

Макеты соответствуют структуре блоков:
шапка → герой/баннер → ленты контента → подвал.

## Концепция оформления
- Фирменный стиль в духе **Кинопоиска**: строгий тёмный фон, фокус на визуале постеров, яркий оранжевый акцент и зелёные рейтинги.
- Карточки: при наведении плавное масштабирование, аккуратная тень без цветных засветов.
- Ленты (новинки, популярное, рекомендации): горизонтальная прокрутка со стрелками. Каталог: адаптивная сетка.
