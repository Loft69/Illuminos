# Дизайн-макеты (Mockup) Illuminos

Реализованы в `public/css/style.css` на Bootstrap 5 (сетка) + CSS-переменные палитры.

## Требования графического дизайна
- Цветовая гамма: тёмная тема (фон #0D0D1A), фиолетовый акцент #6C5CE7,
  золотой рейтинг #F5C518 — гамма гармоничная, англ. контраст WCAG AA.
- Сетка: Bootstrap (container → row → col), карточки контента
  с постерами 2:3, скругление 12 px, тень при наведении.
- Свободное пространство: секции разделены отступами 48 px,
  внутри карточек — 16 px.
- Типографика: системный шрифт (SF/Segoe/Roboto), заголовки 700,
  интерлиньяж 1.5.

## Адаптивные макеты (мобильные / планшетные устройства)
| Устройство        | Брейкпоинт | Сетка карточек          |
|-------------------|------------|-------------------------|
| Смартфон          | < 576 px   | 2 карточки в ряду       |
| Планшет (портрет) | 576–991 px | 3–4 карточки в ряду     |
| Планшет/ноутбук   | 992–1199 px| 4 карточки в ряду       |
| Десктоп           | ≥ 1200 px  | 6 карточек в ряду       |

Макеты соответствуют прототипам из `docs/prototype.md` (структура блоков
шапка → ленты контента → подвал сохранена на всех страницах).

## Обновление оформления
- Идея: ночной кинозал и луч проектора (луч в герое, на постерах и в формах).
- Постеры-заглушки генерируются по жанру: оттенок градиента, крупная буква, название, рейтинг.
- Ленты (новинки, популярное, рекомендации) — горизонтальная прокрутка; число видимых карточек
  соответствует таблице брейкпоинтов выше. Каталог остаётся сеткой.
- Анимация: луч включается один раз при загрузке, смена слайдов героя, отклик на действия
  (избранное, тосты, ошибки форм). Учитывается `prefers-reduced-motion`.
