# Цветовая палитра Illuminos (Стиль Кинопоиск)

Тематика — современный онлайн-кинотеатр: строгий графитовый фон, фирменный оранжевый акцент, зелёные бейджи рейтингов.

| Роль                    | HEX       | Где используется                     |
|-------------------------|-----------|--------------------------------------|
| Основной фон            | `#1D1D1D` | body, подвал                         |
| Фон карточек / шапки    | `#272727` | карточки контента, навигация         |
| Приподнятые поверхности | `#333333` | меню, выпадающие списки, подсказки   |
| Акцент (основной)       | `#FF6C00` | кнопки, активные ссылки, маркеры     |
| Акцент (светлый)        | `#FF9A4D` | текст и подсветка на тёмном фоне     |
| Акцент (hover)          | `#E55F00` | наведение на кнопки                  |
| Рейтинг                 | `#3BB33B` | бейдж рейтинга (зелёный Кинопоиск)   |
| Рейтинг (золото)        | `#F5C518` | звёзды, бейджи                       |
| Основной текст          | `#FFFFFF` | заголовки, основной текст            |
| Вторичный текст         | `#999999` | подписи, описания, плейсхолдеры      |
| Опасность / ошибки      | `#FF4444` | сообщения об ошибках валидации       |
| Успех                   | `#00C853` | сообщения об успехе                  |

Палитра продублирована CSS-переменными в `public/css/style.css` (:root).

## Шрифты
Основной текст, заголовки и интерфейс — **Inter** (Google Fonts, поддержка кириллицы), запасной вариант — `Helvetica Neue, Arial, sans-serif`.
