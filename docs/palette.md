# Цветовая палитра Illuminos

Тематика — онлайн-кинотеатр: ночной кинозал, глубокий тёмно-синий фон,
фиолетовый неоновый акцент (свет проектора), золотой для рейтингов.

| Роль                    | HEX       | Где используется                     |
|-------------------------|-----------|--------------------------------------|
| Основной фон            | `#0D0D1A` | body, подвал                         |
| Фон карточек / шапки    | `#16162B` | карточки контента, навигация         |
| Акцент (основной)       | `#6C5CE7` | кнопки, ссылки, активные элементы    |
| Акцент (рейтинг, золото)| `#F5C518` | бейдж рейтинга, выделение            |
| Основной текст          | `#F5F5FA` | заголовки, основной текст            |
| Вторичный текст         | `#9A9AB0` | подписи, описания, плейсхолдеры      |
| Акцент для текста на тёмном | `#A99DFF` | ссылки и текст акцентного цвета (контраст AA) |
| Свет проектора          | `#FFE9B8` | лучи на постерах и в герое           |
| Опасность / ошибки      | `#E74C3C` | сообщения об ошибках валидации       |
| Успех                   | `#2ECC71` | сообщения об успехе                  |

Палитра продублирована CSS-переменными в `public/css/style.css` (:root).

## Шрифты
Заголовки и логотип — Unbounded, основной текст — Onest (Google Fonts, поддержка кириллицы), запасной вариант — системный шрифт.
